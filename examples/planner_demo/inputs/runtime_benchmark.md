# Runtime Benchmark Notes

This is a synthetic fixture for checking report generation, not a published study.

The evaluation used a fixed hardware configuration throughout the benchmark.
Under that configuration, the optimized runtime completed 120 requests per second and the baseline completed 100 requests per second.
The throughput measurements cover only this benchmark workload; they do not establish performance on other hardware or workloads.

Deployment cost was not measured in this benchmark.
Hardware purchase prices, energy consumption, staffing requirements, and operational expenses were not recorded.
The benchmark therefore does not establish a percentage reduction in deployment cost.
